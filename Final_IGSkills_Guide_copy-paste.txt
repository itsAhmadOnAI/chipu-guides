THE IG GUIDE: your Instagram team inside Claude (free)
(Copy-paste version of the PDF. Checked 2026-11-25 against github.com/sergebulaev/instagram-skills v1.0.34: README, skills/*/SKILL.md, lib/approval.py.)

The tool: Instagram Skills by sergebulaev, MIT licence (free, open source). Claude writes the words (captions, hooks, hashtags, plans,
profile rewrites); you supply the photo or video and post it.

1. INSTALL
   Claude Code (terminal / VS Code / JetBrains):
   /plugin marketplace add sergebulaev/instagram-skills
   /plugin install instagram-skills@instagram-skills
   claude.ai or Claude Desktop: Skills -> Add from GitHub -> sergebulaev/instagram-skills
   Any agent: npx skills add sergebulaev/instagram-skills
   Then just ask about Instagram; the right skill switches on by itself.

THE 9 SKILLS (the reel says 13; v1.0.34 has 9)
   Caption Writer, Carousel Planner, Hook Extractor, Hashtag Strategist, Humanizer, Content Planner, Repurposer,
   Profile Optimizer, Audience Insights.

2. CONTENT IDEAS + CAPTIONS
   Write a caption for this Reel about <topic>. Goal: saves.
   It shortlists 2-3 hook formulas for your goal and you pick one; then it writes the caption (hook in the first 125
   characters, short body, one call to action) and runs the humanizer. It writes the words, not the video: you supply the
   photo or video (Instagram doesn't allow text-only posts).

3. PROFILE CHECK
   Audit my Instagram profile: @yourhandle
   A 9-part scorecard, each part pass / needs work / fail (not a number out of 100): photo, name field, @handle, bio, link,
   category, highlights, first-9 grid, pinned posts. Then before/after rewrites.

4. WEEKLY PLAN
   Plan a week of Instagram content for <niche>. Goal: more saves and follows.
   A 7-day Reels / carousel / story mix with a hook per day, posting times and a saves-and-shares goal.

5. VIRAL REELS IN YOUR NICHE
   What's working in my niche right now? Scan #<hashtag> reels.
   Needs Apify (no Instagram login): token from console.apify.com -> Account -> Integrations, in a .env file:
   APIFY_TOKEN=apify_api_your_token
   Cost: Apify's free plan has a small monthly credit, then scraping is paid per result (checked 2026-11-25: $5 credit,
   then about $2.60 per 1,000 results). No token? Paste the posts you see and it runs the same analysis.
   On claude.ai: use Apify's MCP connector WITH the ?actors= filter from the README (the bare one can run any paid actor).
   Hook Extractor: paste a viral reel's caption/first lines; it names the formula and gives a BLANK TEMPLATE to fill.

POSTING
   Default: Claude shows the draft, you copy the caption and post in the Instagram app.
   Optional Publora (free signup, Instagram Business or Creator account) to upload + schedule:
   PUBLORA_API_KEY=sk_your_key
   INSTAGRAM_PLATFORM_ID=instagram-your_id
   pip install requests python-dotenv
   Every skill shows a draft and waits for your OK. That's a rule the skills follow, not a hard switch in the code,
   so read every draft before you say yes.

Not run on a fresh machine: read the README for the latest steps.
