STEP 1 OF 4
03 / 8
Run /usage
Type it at the Claude Code prompt. That's the whole step.
claude
$   /usage
1
The plan bars
How much of your session and week you have used.
2
What's contributing to your usage?
Rows with a share and a suggested fix, for anything behind 10% or more of your recent usage.
3
The MCP servers table
How much each connected server adds. Press d for the last 24 hours or w for the week.
Don't see the breakdown? It needs a recent Claude Code and a Pro, Max, Ultra, Team or Enterprise plan. Update Claude Code and try again. On an API key, the Session block at the top (token cost) is your main view.

STEP 2 OF 4
04 / 8
Start fresh between tasks
The row you'll see most: Start fresh when you switch tasks. Stale context is sent again with every message, so old chat keeps costing you.
A
Clear it
claude
$   /rename my-login-page
$   /clear
B
Come back later if you need it
claude
$   /resume
C
Need to keep going? Compact it
claude
$   /compact Focus on code samples and API usage
/clear vs /compact: /clear costs nothing. /compact reads the whole conversation to summarize it, so compacting a big context is itself a big request. Use it before you step away, not at the last second.

STEP 3 OF 4
05 / 8
Turn off the skills you don't use
Every skill you have installed adds a short description to each request. A second row on your screen points at them.
A
The fast way
Press f on the /usage screen. Claude checks what you have actually used and proposes a list. It shows each change first and asks before it applies anything.
B
The manual way
Run /skills, highlight a skill, press Space to cycle its state, then Esc to save.
settings: skillOverrides
WHAT /skills WRITES
{
"skillOverrides"  : {
"deploy"  :
"off"
}
}
Plugin skills are different: the docs say skillOverrides doesn't affect them. Manage those with /plugin instead. And keep anything you really use: only "off" hides a skill completely.
